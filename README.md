# Studio site

Marketing site for the apps we sell, starting with WTF POS. Astro, TypeScript and Tailwind CSS.

## Run it

```bash
npm install
npm run dev      # http://localhost:4321
npm run check    # astro check
npm run build    # static output in dist/
npm run preview  # serve the build
```

Project rules and the roadmap are in `CLAUDE.md` and `docs/ROADMAP.md`.
